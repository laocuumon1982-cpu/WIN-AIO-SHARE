WIN AIO BY DUY ANH - v3.8
=========================

CHỈ 1 FILE EXE
  - Chép "Win AIO by Duy Anh.exe" vào USB / ổ nào cũng được rồi chạy. Không cần cài.
  - Tool tự xin quyền Administrator (Windows hiện hộp UAC, bấm Yes).
  - Mở tool: cửa sổ phóng to toàn màn hình, vào trang Thông tin & khởi động. Nút trong các trang tự to / nhỏ cho vừa màn hình.
  - Thư mục Data kế bên exe CHỈ được tạo khi: tải app, sửa nút (Admin), đổi cài đặt / giao diện, sao lưu Wifi - Driver.
    Mở tool để xem thông tin, tắt máy, tháo ổ... thì không tạo gì thêm.
  - Máy chưa có Edge WebView2 (Win 10 cũ / LTSC): tool tự mở giao diện bằng trình duyệt Edge. Đóng tab là tool tự thoát.

MỞ TOOL BẰNG 1 DÒNG LỆNH (không cần USB)
  - Bấm chuột phải nút Start -> Terminal / Windows PowerShell, gõ (hoặc dán) rồi Enter:
      irm https://raw.githubusercontent.com/laocuumon1982-cpu/WIN-AIO-SHARE/main/aio.ps1 | iex
  - Hoặc Win + R, dán dòng sau rồi Enter:
      powershell irm https://raw.githubusercontent.com/laocuumon1982-cpu/WIN-AIO-SHARE/main/aio.ps1 | iex
  - Lệnh tự tải bản mới nhất về %LOCALAPPDATA%\WinAIO rồi mở tool (bấm Yes ở hộp UAC). Thư mục Data cũng nằm ở đó.
    Chạy lại lần sau: đã có bản mới nhất thì mở luôn, không tải lại.

NGUỒN "github:" (v2.1.9) - link không bao giờ cũ

WINGET NHANH & TỰ KIỂM TRA (v2.1.7)
  - Mở tool: tự chỉnh winget tải trực tiếp (nhanh hơn), làm mới kho winget, kiểm tra từng nút WINGET.
  - Rê chuột lên nút WINGET để xem bản mới nhất trong kho. Nhãn đỏ "ID LỖI" = gói không còn trong kho:
    tool đã thử tự tìm ID mới theo tên nút mà không được -> bật Admin, bấm ✎ để sửa ID hoặc đổi sang link tải.
  - Muốn giữ cấu hình winget gốc: sửa config.json, thêm "winget_fast": false.

WINGET TỰ CẬP NHẬT
  - Mở tool sẽ so bản winget trên máy với bản mới nhất của Microsoft. Bản cũ / chưa có -> tự cài bản mới, chạy ngầm.
  - Đèn "winget" bên trái: vàng = đang cập nhật, xanh = đã là bản mới nhất. Bấm nút WINGET lúc đang cập nhật thì tool chờ xong mới cài.
  - Tắt tính năng này: Cài đặt (Admin) -> bỏ tick "Mở tool tự kiểm tra winget...".

CẬP NHẬT
  - Nút "⟳ Cập nhật" góc trên phải: kiểm tra bản mới ở github.com/laocuumon1982-cpu/WIN-AIO-SHARE (mục Releases),
    tải về, tự thay file exe rồi mở lại. Dữ liệu trong Data giữ nguyên.
  - Mở tool sau 4 giây sẽ tự kiểm tra; có bản mới thì nút chuyển xanh "⟳ Có bản vX.Y".

KHỞI ĐỘNG ĐẶC BIỆT (tab Hệ thống) - máy khởi động lại NGAY sau khi xác nhận, lưu công việc trước
  - Vào BIOS / UEFI. Máy Legacy BIOS: khởi động lại rồi bấm phím của hãng (F2, Del, F10, Esc).
  - Chọn ổ khởi động: cắm USB trước, chọn mục rồi khởi động 1 lần từ đó. Lần sau máy trở lại thứ tự cũ.
  - Vào Safe Mode (Tối giản / Có mạng / Command Prompt): máy sẽ vào Safe Mode MỖI LẦN khởi động cho tới khi
    bấm "Thoát Safe Mode" (chạy Win AIO ngay trong Safe Mode để bấm). Nút này sáng xanh khi đang đặt Safe Mode.
  - Menu Recovery nâng cao: Startup Repair, System Restore, Startup Settings, gỡ bản cập nhật...

TEST MÁY (kiểm tra laptop / PC)
  - Mỗi mục bấm "▶ Bắt đầu test", xong bấm ✓ Đạt hoặc ✗ Lỗi. Trên cùng là PHIẾU KIỂM TRA, bấm "⧉ Copy phiếu" để gửi khách.
  - Màn hình: bấm chuột / → / Space đổi màu, ← lùi, Esc thoát. Cảm ứng: chạm kín các ô, nhấp đúp / Esc thoát.
  - Bàn phím: bấm lần lượt các phím; bấm Esc 2 lần liền để thoát. Phím Fn và phím riêng của hãng Windows không báo.
  - Micro / Webcam: lần đầu Windows hỏi quyền -> bấm Cho phép (Allow). Không mở được thì vào Cài đặt -> Quyền riêng tư.
  - Sức khỏe ổ cứng: Tốt / Cảnh báo / Hỏng theo SMART, lỗi đọc ghi không sửa được, nhiệt độ, hao mòn SSD, giờ chạy.
    Ổ báo HỎNG / SẮP HỎNG: sao lưu dữ liệu ngay. Ô "—" là ổ không báo chỉ số đó (ổ USB, ổ qua RAID).
  - Pin: độ chai = phần dung lượng đã mất so với lúc mới. Trên 20% là chai vừa, trên 40% nên thay pin.

KHO ISO WIN (v2.3.2)

  - "⬆ Cập nhật" từng dòng, hoặc tick nhiều rồi "Cập nhật mục đã chọn" / "Cập nhật tất cả". Nên đóng phần mềm trước.

QUẢN LÝ (v2.1)
  - Khởi động cùng Windows: chọn mục (bấm vào dòng) -> Vô hiệu / Kích hoạt (giống Task Manager), Xóa (có lưu bản sao
    trong Data\Backup), Mở vị trí file. Cột "Nhà phát hành" để nhận ra chương trình lạ.
  - Gỡ phần mềm tận gốc: bấm "🗑 Gỡ" -> chạy trình gỡ của phần mềm (có thể gỡ im lặng), xong tool tìm thư mục và registry
    còn sót. Bỏ tick mục muốn giữ rồi bấm Xóa. Cửa sổ gỡ của phần mềm còn mở thì làm xong rồi bấm "Quét lại".
  - Ứng dụng MS Store: tick nhiều ứng dụng rồi gỡ 1 lần (có tùy chọn gỡ cho mọi tài khoản). Ứng dụng hệ thống đã được ẩn.
  - Defender & bảo mật: bảng trạng thái, bật / tắt Realtime, Cloud, gửi mẫu, Firewall, SmartScreen, UAC; thêm / bỏ ngoại lệ.
    Tamper Protection đang bật thì Windows chặn đổi Defender -> tắt nó trong Windows Security trước.

DỌN DẸP (v2.1)
  - Dọn rác hệ thống: bấm Quét để đo, tick mục muốn dọn. Cache trình duyệt không xóa mật khẩu / lịch sử / dấu trang.
  - Phân tích ổ đĩa: xem thư mục nào chiếm nhiều chỗ, bấm tên thư mục để xem sâu hơn, ⬆ để lên thư mục cha.
  - Cache CapCut PC: xóa cache dựng video, dự án giữ nguyên (CapCut đang mở sẽ được tắt).
  - Virus macro Excel: tìm file lạ tự mở cùng Excel (XLSTART) -> cách ly vào Data\Backup; đặt lại Excel không tự chạy macro.
  - Xóa metadata ảnh JPG / PNG (GPS, máy chụp...): ảnh gốc giữ nguyên, ảnh sạch lưu trong thư mục con "Da_xoa_metadata".

NGUỒN & Ổ USB (gộp từ Power & USB Eject)
  - TẮT MÁY NGAY: ép tắt ngay, không hỏi lại (dùng khi khẩn cấp).

  - Hẹn giờ tắt máy (luôn force): "Sau thời gian" N phút, hoặc "Vào lúc" giờ:phút (giờ đã qua -> ngày mai). Hủy hẹn được.

      ⏏ Tháo an toàn: giống Safely Remove Hardware của Windows. Windows từ chối thì báo lý do (chương trình đang mở tệp...).
      ⚡ Ép ngắt ổ: ghi hết dữ liệu + dismount + Offline rồi tháo. Cắm lại hoặc khởi động lại máy là ổ tự Online.

CÀI PHẦN MỀM
  - Bấm 1 nút: cài ngay. Bấm ô tròn bên trái để chọn nhiều mục, rồi "▶ Cài mục đã chọn".

  - Đèn trên nút: vàng = đang cài / chờ, xanh = xong, đỏ = lỗi (xem tab Nhật ký).

    không báo tiến độ nên % là ƯỚC TÍNH theo thời gian (tới 95%, cài xong mới 100%). Nút đang chạy cũng hiện %.

MS OFFICE (nút trong nhóm VĂN PHÒNG - PDF)
  - Chọn phiên bản 2016 / 2019 / 2021 / 2024 / 365, biến thể, 64/32-bit, ngôn ngữ, ứng dụng (thêm Project / Visio) rồi bấm ⚙ CÀI ĐẶT.

  - "⬇ Tải thư viện offline": tải bộ cài về Soft\Office kế bên exe (2-4 GB). Có thư viện rồi thì lần sau cài không cần mạng.
  - "🗑 Gỡ Office cũ": gỡ toàn bộ Office trên máy. "🔗 Ghim Desktop", "🔍 Bản quyền", "🔑 Nhập key Office" (key của bạn).

CHẾ ĐỘ ADMIN (sửa nút)
  - Bấm "🔒 Admin" -> nhập mật khẩu. MẬT KHẨU MẶC ĐỊNH: HP360 (viết hoa HP)  (đổi trong tab Cài đặt).
  - Cạnh mỗi nút hiện nút vàng ✎: sửa tên, biểu tượng, đổi NGUỒN APP, tham số cài, ghi chú, chuyển nhóm, lên / xuống, xóa.
  - Mỗi nhóm có "＋ Thêm phần mềm"; thanh Admin có "＋ Thêm nhóm" và "Số cột" (2-6).
  - "Kiểu xếp" trên thanh Admin: Lưới (thẳng hàng, mặc định) hoặc Cột dọc.
  - Đổi vị trí NHÓM, dưới tên nhóm bấm ◀ ▲ ▼ ▶:
      Lưới:    đổi chỗ với nhóm bên trái / hàng trên / hàng dưới / bên phải (mỗi nhóm hiện "Hàng · Cột").
      Cột dọc: ▲ ▼ lên / xuống trong cột, ◀ ▶ sang cột trái / phải.
  - Đổi vị trí NÚT trong nhóm: bấm ▲▼ nhỏ cạnh nút ✎. Đầu nhóm có ✎ đổi tên, ✕ xóa nhóm.

  office:                     mở cửa sổ cài MS Office.
