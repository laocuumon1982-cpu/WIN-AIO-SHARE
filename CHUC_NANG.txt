=====================================================================
           WIN AIO BY DUY ANH - DANH SÁCH CHỨC NĂNG (v2.7)
=====================================================================
Tool cài Win dạo 1 file exe portable (không cần cài đặt), giao diện tiếng Việt.
Tải: https://github.com/laocuumon1982-cpu/WIN-AIO-SHARE/releases/latest
Mở nhanh bằng 1 dòng lệnh PowerShell (không cần USB):
  irm https://raw.githubusercontent.com/laocuumon1982-cpu/WIN-AIO-SHARE/main/aio.ps1 | iex


---------------------------------------------------------------------
CHUNG
---------------------------------------------------------------------
- 1 file exe duy nhất, tự xin quyền Administrator.
- Mở là phóng to toàn màn hình, vào trang Thông tin & khởi động.
- Giao diện tự co giãn vừa 1 màn hình (không phải kéo), sáng / tối.
- Thư mục Data (kế bên exe) chỉ tạo khi cần: lưu file tải về, sao lưu, nhật ký.
- Nút ⟳ Cập nhật: tải bản mới từ GitHub và tự mở lại.
- Không cần mật khẩu khi mở tool. Mật khẩu Admin (mặc định: HP360) để:
    sửa tên / biểu tượng / link nguồn từng nút, thêm / xóa nút và nhóm,
    kéo thả nhóm và nút để sắp xếp (chuyển nút sang nhóm khác), đổi kiểu xếp,
    sao lưu / nhập danh sách nút (JSON).
- Bảng đèn trạng thái: quyền Admin, Internet, winget, hàng đợi cài,
  hẹn giờ tắt máy, chế độ Admin.
- Tự kiểm tra winget, máy có winget cũ thì tự cài bản mới trong im lặng.
- winget tải nhanh (tải trực tiếp); mở tool tự kiểm tra từng nút WINGET, ID hỏng
  thì tự tìm ID mới theo tên, không được thì báo nhãn "ID LỖI".
- Nhật ký: lịch sử cài đặt và thao tác.


---------------------------------------------------------------------
HỆ THỐNG
---------------------------------------------------------------------
[Thông tin & khởi động]
- Tên máy, Windows, CPU, RAM (từng khe), card màn hình, mainboard / BIOS,
  mạng (IP, MAC, tốc độ), ổ cứng và phân vùng (dung lượng, loại SSD/HDD).
- Theo dõi trực tiếp % CPU, % RAM, nhiệt độ CPU (máy có cảm biến), thời gian máy đã chạy.
- Khởi động đặc biệt: vào BIOS / UEFI, vào Recovery (WinRE),
  chọn ổ khởi động 1 lần, Safe Mode, trở về khởi động bình thường.
- Mở nhanh: Thông tin máy, Device Manager, Disk Management, Control Panel,
  Task Manager, Services, Registry, Group Policy, CMD Admin,
  PowerShell Admin, Kết nối mạng, Âm thanh, DxDiag, System Properties,
  Programs & Features, Event Viewer.

[Quản lý]
- Khởi động cùng Windows: xem danh sách, nhà phát hành, vô hiệu /
  kích hoạt / xóa (có lưu bản sao) / mở vị trí file.
- Gỡ phần mềm tận gốc: chạy trình gỡ (có gỡ im lặng), sau đó tìm và xóa
  thư mục, registry còn sót.
- Ứng dụng MS Store: chọn nhiều ứng dụng gỡ 1 lần, gỡ cho mọi tài khoản.
- Defender & bảo mật: bảng trạng thái; bật / tắt Realtime, Cloud,
  gửi mẫu tự động, Firewall, SmartScreen, UAC; thêm / bỏ ngoại lệ
  (thư mục, tiến trình, đuôi file).
- Cập nhật app (v2.5): liệt kê phần mềm đã cài có bản mới (winget) - phiên bản đang dùng,
  bản mới, nút Cập nhật từng cái / đã chọn / tất cả; mở tool tự kiểm tra, menu Quản lý hiện số.

[Nguồn & Ổ USB]  (gộp từ Power & USB Eject)
- Tắt máy ngay (ép đóng ứng dụng), khóa máy, đổi người dùng.
- Hẹn giờ tắt máy: sau X phút hoặc vào lúc giờ cố định, hủy hẹn.
- Ổ đĩa ngoài: tháo an toàn ổ USB / ổ cứng gắn ngoài, ép ngắt khi bị kẹt.

[MS Office]
- Cửa sổ cài Office riêng: chọn phiên bản, bộ ứng dụng, ngôn ngữ,
  tải từ máy chủ Microsoft và cài (Office Deployment Tool).

[Kho bộ cài WIN] (v2.3.2, đổi tên ở v2.7)
- Chọn Windows 11 / Windows 10, ngôn ngữ, 32 / 64-bit, nơi lưu -> "Tải ISO": tool tự lấy
  link gốc của Microsoft và tải trong tool (có %, tốc độ, Dừng, tải tiếp từ chỗ dừng).
- "Chỉ lấy link" để dán vào IDM (link dùng được 24 giờ).
- Khung massgrave.dev: nút mở trang tải Windows 11, 10, LTSC, ARM64, Server, 8.1, 8, 7, danh sách đầy đủ.
- Kiểm tra SHA-256 file ISO (có %), dán mã công bố để so trùng khớp hay không.

[Tiện ích Windows]
- THIẾT LẬP WINDOWS: hiện đuôi file, This PC ra Desktop, tắt Fast Startup,
  tắt ngủ đông, múi giờ Việt Nam, khởi động lại Explorer,
  xóa / hiện lại mũi tên shortcut, menu chuột phải kiểu cũ / kiểu Win 11.
- MICROSOFT DEFENDER: tắt / bật Real-time Protection, xem trạng thái,
  mở Windows Security.
- WINDOWS UPDATE: tắt / bật lại, mở Windows Update.
- MẠNG: DNS Google 8.8.8.8, DNS Cloudflare 1.1.1.1, DNS tự động,
  xóa cache DNS, xem mật khẩu Wifi đã lưu, reset mạng (Winsock, TCP/IP).
- DỌN DẸP: xóa file tạm, dọn thùng rác, Disk Cleanup.
- MÁY IN: khởi động lại Spooler, xóa hàng đợi in, Máy in & thiết bị.
- BITLOCKER: xem trạng thái, tắt BitLocker ổ C.
- SAO LƯU - KHÔI PHỤC: sao lưu / khôi phục Wifi, sao lưu / khôi phục
  Driver, tạo điểm khôi phục.
- BẢN QUYỀN (KEY CỦA BẠN): xem trạng thái bản quyền, nhập key Windows,
  mở trang Kích hoạt.


---------------------------------------------------------------------
DỌN DẸP & SAO LƯU
---------------------------------------------------------------------
[Dọn dẹp]
- Dọn rác hệ thống có đo dung lượng trước: file tạm, bộ cài Windows Update,
  Delivery Optimization, file dump lỗi, cache ảnh thu nhỏ,
  cache trình duyệt, thùng rác.
- Phân tích ổ đĩa: thư mục nào chiếm nhiều dung lượng, xem sâu từng cấp.
- Xóa cache CapCut PC (giữ nguyên dự án).
- Virus macro Excel: quét file lạ tự mở cùng Excel (XLSTART), cách ly,
  đặt lại Excel không tự chạy macro.
- Xóa metadata ảnh JPG / PNG (GPS, máy chụp, giờ chụp...).

[Sao lưu]
- Thư mục người dùng: Desktop, Tài liệu, Tải về, Ảnh, Video, Nhạc
  (sao lưu và khôi phục, chọn ổ lưu).
- Zalo PC: sao lưu / khôi phục tin nhắn, ảnh, file (tự tắt Zalo).
- Zalo nhiều tài khoản: mỗi tài khoản 1 cửa sổ Zalo riêng.
- Trình duyệt Chrome, Edge, Cốc Cốc, Brave, Firefox: dấu trang,
  tiện ích, mật khẩu, lịch sử, cài đặt.
- Chuyển phần mềm sang Win mới (v2.6): lưu danh sách phần mềm đang cài (winget export)
  vào USB; cài Win xong mở tool, chọn file danh sách, bỏ tick mục không cần, cài lại hết.


---------------------------------------------------------------------
SỬA LỖI & THIẾT LẬP (v2.6)
---------------------------------------------------------------------
[Sửa lỗi Windows 1 chạm]
- Sửa tất cả file hệ thống: DISM RestoreHealth rồi SFC /scannow.
- SFC /scannow, DISM RestoreHealth riêng lẻ (có % tiến độ, xem chi tiết kết quả).
- Reset Windows Update (xóa bộ nhớ đệm SoftwareDistribution, catroot2).
- Reset Microsoft Store.
- Sửa lỗi chia sẻ máy in 0x0000011b / 0x00000709 (làm trên cả máy chủ và máy con).
[Dọn Win 11 cho gọn]
- 1 nút tắt Copilot, Recall, quảng cáo / gợi ý Start menu và màn hình khóa,
  Widgets, gửi dữ liệu chẩn đoán, quảng cáo cá nhân hóa, gợi ý Bing khi tìm.
- Nút "Bật lại như cũ".
[Thiết lập máy mới]
- Đổi tên máy, tạo tài khoản Windows (thường / quản trị, có hoặc không mật khẩu).
- Bỏ mật khẩu đăng nhập tài khoản cục bộ; mở netplwiz.
- Đặt Chrome làm trình duyệt mặc định (Windows bắt bấm xác nhận 1 lần).
- Cho UniKey chạy cùng Windows (tự tìm UniKey trên máy).
[Bộ font tiếng Việt]
- Cài VNI, TCVN3 (.VnTime...), Unicode: từ link .zip Admin gắn 1 lần,
  hoặc từ file .zip / file font / thư mục. Bỏ qua font máy đã có.

[Hồ sơ cài đặt] (tab Cài phần mềm › 📋 Hồ sơ cài đặt)
- Mặc định: Máy văn phòng, Máy kế toán, Máy game.
- Bấm 1 lần: cài cả bộ phần mềm, chạy tiện ích Windows, dọn Win 11, cài font.
- Admin thêm / sửa / xóa hồ sơ (chọn phần mềm, tiện ích). Đi kèm file sao lưu JSON.

[Kho bộ cài Mac] (v2.7)
- Giống trình tải của macUSB: đọc danh mục bộ cài macOS trực tiếp từ máy chủ Apple.
- macOS 11 trở lên (Tahoe, Sequoia, Sonoma, Ventura, Monterey, Big Sur): 1 file InstallAssistant.pkg.
- macOS 10.13 - 10.15: tải đủ bộ 3 file của Apple vào 1 thư mục.
- macOS 10.7 - 10.12: file .dmg từ trang hỗ trợ của Apple.
- Mặc định hiện bản mới nhất mỗi đời; bấm 1 đời để xem các bản cũ. Tải có %, tải tiếp, hoặc chép link cho IDM.

[Kho iOS] (v2.7)
- Danh sách thiết bị và firmware IPSW theo ipsw.me: iPhone, iPad, iPod, Apple TV, HomePod, Mac chip M.
- Tìm máy theo tên / mã máy; xem phiên bản, build, ngày, dung lượng, bản Apple còn ký.
- Tải file IPSW từ máy chủ Apple (có %, tải tiếp) hoặc chép link.

[Kho bộ cài WIN › Tạo USB boot Ventoy]
- Liệt kê USB đang cắm (chỉ ổ USB, không bao giờ đụng ổ Windows).
- Tự tải Ventoy mới nhất, cài vào USB (MBR hoặc GPT), xác nhận gõ XOA trước khi xóa USB.
- Chép file ISO (đã tải trong Kho bộ cài WIN hoặc chọn file khác) vào USB Ventoy, có %.

[Quản lý › Driver]
- Liệt kê thiết bị lỗi / thiếu driver (dấu chấm than vàng), lý do lỗi, mã phần cứng.
- Tìm driver qua Windows Update, chọn và cài.

- Sức khỏe ổ cứng: SMART, dự báo hỏng, nhiệt độ, độ hao mòn SSD, giờ chạy.

- Hiệu năng nhanh (v2.6): đo tốc độ đọc / ghi tuần tự, đọc ngẫu nhiên 4K của ổ cứng
  (WinSAT có sẵn của Windows), chạy tải 100% CPU 1 / 3 / 5 phút, vẽ biểu đồ nhiệt độ,
  xung nhịp, tải CPU, báo CPU có hạ xung vì nóng không.
- Tổng kết kết quả các bài test, sao chép báo cáo.
